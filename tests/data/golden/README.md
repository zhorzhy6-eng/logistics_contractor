# Золотые эталоны договоров

Выводы генераторов (Шаг 0 рефакторинга архитектуры контрактов) на облегчённых копиях реальных шаблонов (без встроенных шрифтов).

Сценарии перевозки (`ContractGenerator`): `ooo`, `ip_with_vat`, `ip_without_vat`, `gap` (маршрут с пустой точкой).

Для каждого сценария: `<сценарий>.docx` — документ, `<сценарий>.json` — структурный отпечаток для сверки в `tests/test_contract_generator_golden.py`.

Эталоны клиентских типов приходят из приватной части проекта: сценарии описаны в её `tools/golden_scenarios.py`, а файлы появляются в этой папке при её наличии (см. `docs/PRIVATE_MIGRATION.md`).

Перегенерация: `python tools/make_golden.py [сценарий ...]`.
Без аргументов перегенерируются ВСЕ эталоны (включая клиентские, если приватная часть подключена).

Все данные синтетические, реальных ПДн нет.
