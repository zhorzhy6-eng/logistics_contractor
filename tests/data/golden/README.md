# Золотые эталоны договоров

Выводы `ContractGenerator` (Шаг 0 рефакторинга архитектуры контрактов) на облегчённых копиях реальных шаблонов (без встроенных шрифтов).

Сценарии: `ooo`, `ip_with_vat`, `ip_without_vat`, `gap` (маршрут с пустой точкой). Для каждого: `<сценарий>.docx` — документ, `<сценарий>.json` — структурный отпечаток для сверки в `tests/test_contract_generator_golden.py`.

Перегенерация: `python tools/make_golden.py`.

Все данные синтетические, реальных ПДн нет.
