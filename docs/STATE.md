## Известные расхождения / замечания

### Данные и бланк

- В бланке Хавалов общие сведения (лот, маршрут, автовоз, водитель, план
  погрузки, ставка) повторяются в каждой строке. Промпт берёт их **один раз**,
  при расхождении — из первой заполненной строки. В `vehicles` идут только
  `vin / brand / model / dealer / dealer_code`.
- Литералы сторон: `Сюрлогистик` (Заказчик) + `ООО ТЕХНОЛОГИСТИКА`
  (Перевозчик). В бланке напечатано `ООО "ТЕХНОЛОГИСТИКА"` — в промпте
  оговорено, чтобы модель не добавляла кавычки.
- Плейсхолдер `<<PERSON_1>>` для ФИО целиком кладётся в `driver_last_name`,
  имя/отчество остаются пустыми. Токен **не делится** на части.
- `vat_rate` в бланк не пишется — для «22%» в форме нет ни ячейки, ни
  подписи. Читается обратно пустым; в `UNMAPPED_ZAYAVKA_FIELDS`.
- `customer_name`, `carrier_name` не читаются из файла, а подставляются
  константами — они в бланке напечатаны и не меняются.
- При 0 машин общие сведения не попадают в файл (город, автовоз, водитель):
  в бланке это колонки ТАБЛИЦЫ, и без строк писать их некуда. Валидатор
  предупреждает.

### Технические ловушки (найдены в A.3–A.4)

- **openpyxl 3.1.5, удаление строк:** `del ws.row_dimensions[row]`
  сдвигает ключи ниже удалённого (`KeyError` при втором удалении);
  `ws.delete_rows` не двигает merged-диапазоны. Обход в
  `core/contracts/zayavka/postprocess.py`: `_drop_row_heights` +
  `_shift_merged_ranges`.
- **openpyxl, запись в merged-ячейку:** писать можно **только в левый
  верхний угол** объединения. Генератор это делает через `_anchor_cell`;
  внешний код наступит.
- **`_guard_same_file`:** правка поля в тот же день и в ту же папку
  падает с `ZayavkaTemplateError` — исходный файл не затирается
  (задумано в A.3). Если в UI это неудобно — пересмотреть в B.3
  (кандидат в ADR).
- **Имя файла зависит только от даты заявки** —
  `output/Заявка_Хавалы_<дата ISO>.xlsx`. Совпадающая дата → отказ
  от перезаписи.
- **`TITLE` есть только у Хавалов.** У DOCX-типов название типа
  берётся из реестра (`spec.title`), атрибута `TITLE` у них нет.
  Это **разница контрактов**, не поломка.
- **`get_prompt("perevozka") is None` — норма.** У перевозки своего
  промпта нет, распознавание берёт дефолтный GigaChat. Тест «у всех
  пяти промпт непустой» был бы ловушкой на задуманное поведение.
- **Два pytest с общим `--basetemp` нельзя.** Один прогон за раз.
