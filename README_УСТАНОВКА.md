# Установка Logistics Contractor

Программа для подготовки договоров перевозки, аренды и заявок
(5 типов). Эта инструкция — для того, кто ставит её первый раз.

## Что нужно

* Windows 10 или 11, **64-bit**.
* Ключ **GigaChat** (Sber Developer Studio) — для распознавания документов
  и помощника Максимилиана.
* Ключ **DaData** (dadata.ru) — для подсказок по ИНН и адресам.

Ключи не входят в установщик: их вводят при первом запуске (шаг 3).

## Установка

1. Запустите `LogisticsContractor_Setup_v1.4.1.exe`.
2. Следуйте инструкциям: **Далее → Далее → Установить**.
3. Поставьте галочку «Запустить программу» или запустите ярлык
   **Logistics Contractor** с рабочего стола.

Установка **пользовательская**: программа ставится в
`%LOCALAPPDATA%\Programs\LogisticsContractor`, права администратора не
нужны. Так сделано специально: часть служебных файлов (правовая база,
сертификаты, отчёт самопроверки) программа обновляет рядом с собой, а в
`Program Files` обычный пользователь писать не может.

**Данные пользователя** (договоры, настройки, журналы) лежат отдельно —
в `%APPDATA%\LogisticsContractor` (см. раздел «Что и где лежит»).

## Первый запуск: ключи

При первом запуске, если ключа ещё нет, программа сама откроет окно
**«Ключи API»**:

* **GigaChat → Authorization key** — из личного кабинета Sber Developer
  Studio, раздел «Authorization key» (это Base64-строка). Ключ
  вставляется целиком, без слова `Basic`.
* **DaData → API key** — из личного кабинета dadata.ru, раздел
  «API-ключи».
* **DaData → Secret key** — только если нужна очистка адресов
  (необязательное поле).

Кнопка **«Сохранить»** кладёт ключи в системное хранилище Windows
(«Диспетчер учётных данных»), а не в файлы программы: в папке с
программой ключей нет, и в настройках они не видны. Поэтому же ключи не
попадают в резервные копии папки.

Окно можно закрыть кнопкой **«Отмена»** — программа запустится и без
ключей: будут доступны генерация по шаблонам и ручное заполнение формы,
а распознавание документов и Максимилиан — нет. Ввести ключи позже можно
в **Настройки → GigaChat → «Ключи API…»**.

## Где взять ключи

* GigaChat: <https://developers.sber.ru/portal/products/gigachat-api>
* DaData: <https://dadata.ru/api/>

Ссылки на эти кабинеты есть и в самом окне ключей.

## Если что-то не работает

| Что случилось | Что делать |
|---|---|
| GigaChat не отвечает | Настройки → «Ключи API…» → введите ключ заново. Проверьте срок действия ключа в кабинете Sber. |
| DaData не подставляет ИНН | То же окно ключей: проверьте «API key» (не «Secret key»). |
| «Системное хранилище Windows недоступно» | Проверьте, что служба «Диспетчер учётных данных» работает (services.msc → Credential Manager). |
| Не открывается DOC-файл | Для старых `.doc` нужен LibreOffice (поле «LibreOffice soffice» в настройках). |
| Ошибка сертификата GigaChat | Сертификат НУЦ Минцифры уже входит в сборку; если появилось сообщение — см. «Журналы». |

**Журналы:** `%APPDATA%\LogisticsContractor\logs\`
(`app.log`, `errors.log`, `audit.log`; с флагом `--debug` — ещё
`debug.log`). В журналах нет персональных данных — только имена полей,
количества и длины.

## Что и где лежит

| Что | Где |
|---|---|
| Настройки | `%APPDATA%\LogisticsContractor\config\settings.json` |
| База договоров | `%APPDATA%\LogisticsContractor\contracts.db` |
| Готовые договоры | `%APPDATA%\LogisticsContractor\output\<Водитель_И.О._маршрут_дата>\` |
| Журналы | `%APPDATA%\LogisticsContractor\logs\` |
| Программа | `%LOCALAPPDATA%\Programs\LogisticsContractor\` |
| Шаблоны, правовая база, иконки | `%LOCALAPPDATA%\Programs\LogisticsContractor\_internal\` (не менять) |

`%APPDATA%` — это `C:\Users\<Имя>\AppData\Roaming`. Папку данных можно
открыть и так: в окне программы **Настройки → «Открыть папку данных»**
(если пункт есть) или вставьте путь в адресную строку Проводника.

Почему данные отдельно от программы: папку программы установщик при
обновлении заменяет, и всё, что в ней лежало, пропадало. Папку
`%APPDATA%\LogisticsContractor` установщик не трогает никогда — ни при
установке новой версии, ни при удалении программы.

## Обновление программы

Для обновления:

1. Скачайте новый установщик (например, LogisticsContractor_Setup_v1.4.1.exe).
2. Запустите его.
3. Следуйте инструкциям (Далее → Далее → Установить).
4. Программа запустится с новой версией.

**Ваши данные сохранятся** — они хранятся в:
`C:\Users\<Имя>\AppData\Roaming\LogisticsContractor\`
(договоры, настройки, логи).

Ключи API (GigaChat, DaData) тоже сохранятся — они в Windows Credential Manager.

Если вы ставили версию **1.4.0 или старше**, данные лежали в папке
программы. При первом запуске новой версии программа **сама скопирует**
их в `%APPDATA%\LogisticsContractor` — база и настройки будут на месте,
а старые файлы останутся в папке программы (их можно удалить вручную,
когда убедитесь, что всё в порядке).

## Удаление

**Параметры → Приложения → Logistics Contractor → Удалить** (или ярлык
«Удалить Logistics Contractor» в меню «Пуск»).

Удаляются программа и её служебные файлы. **Данные в
`%APPDATA%\LogisticsContractor` остаются** — база, настройки и готовые
договоры. Если они больше не нужны, удалите эту папку вручную. Ключи API
тоже остаются в системном хранилище Windows: их удаляют в «Диспетчере
учётных данных».

## Для разработчика

Пересборка exe и установщика одной командой:

```
.\rebuild.ps1
```

Скрипт прогоняет тесты (unit → integration → ui → раскладка), собирает
`dist\LogisticsContractor\LogisticsContractor.exe` через PyInstaller и
установщик `installer\LogisticsContractor_Setup_vX.Y.Z.exe` через Inno
Setup, после чего печатает путь к готовому файлу. Нужен Inno Setup 7
(скрипт находит его сам; свой путь можно задать переменной `ISCC_PATH`).
