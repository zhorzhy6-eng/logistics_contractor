# Установка Logistics Contractor

Программа для подготовки договоров перевозки, аренды и заявок
(5 типов). Эта инструкция — для того, кто ставит её первый раз.

## Что нужно

* Windows 10 или 11, **64-bit**.
* Ключ **GigaChat** (Sber Developer Studio) — для распознавания документов
  и помощника Максимилиана.
* Ключ **DaData** (dadata.ru) — для подсказок по ИНН и адресам.

Ключи не входят в установщик: их вводят при первом запуске (шаг 3).

## Установка

1. Запустите `LogisticsContractor_Setup_v1.4.0.exe`.
2. Следуйте инструкциям: **Далее → Далее → Установить**.
3. Поставьте галочку «Запустить программу» или запустите ярлык
   **Logistics Contractor** с рабочего стола.

Установка **пользовательская**: программа ставится в
`%LOCALAPPDATA%\Programs\LogisticsContractor`, права администратора не
нужны. Так сделано специально: программа пишет рядом с собой настройки,
базу, журналы и готовые договоры, а в `Program Files` обычный
пользователь писать не может.

## Первый запуск: ключи

При первом запуске, если ключа ещё нет, программа сама откроет окно
**«Ключи API»**:

* **GigaChat → Authorization key** — из личного кабинета Sber Developer
  Studio, раздел «Authorization key» (это Base64-строка). Ключ
  вставляется целиком, без слова `Basic`.
* **DaData → API key** — из личного кабинета dadata.ru, раздел
  «API-ключи».
* **DaData → Secret key** — только если нужна очистка адресов
  (необязательное поле).

Кнопка **«Сохранить»** кладёт ключи в системное хранилище Windows
(«Диспетчер учётных данных»), а не в файлы программы: в папке с
программой ключей нет, и в настройках они не видны. Поэтому же ключи не
попадают в резервные копии папки.

Окно можно закрыть кнопкой **«Отмена»** — программа запустится и без
ключей: будут доступны генерация по шаблонам и ручное заполнение формы,
а распознавание документов и Максимилиан — нет. Ввести ключи позже можно
в **Настройки → GigaChat → «Ключи API…»**.

## Где взять ключи

* GigaChat: <https://developers.sber.ru/portal/products/gigachat-api>
* DaData: <https://dadata.ru/api/>

Ссылки на эти кабинеты есть и в самом окне ключей.

## Если что-то не работает

| Что случилось | Что делать |
|---|---|
| GigaChat не отвечает | Настройки → «Ключи API…» → введите ключ заново. Проверьте срок действия ключа в кабинете Sber. |
| DaData не подставляет ИНН | То же окно ключей: проверьте «API key» (не «Secret key»). |
| «Системное хранилище Windows недоступно» | Проверьте, что служба «Диспетчер учётных данных» работает (services.msc → Credential Manager). |
| Не открывается DOC-файл | Для старых `.doc` нужен LibreOffice (поле «LibreOffice soffice» в настройках). |
| Ошибка сертификата GigaChat | Сертификат НУЦ Минцифры уже входит в сборку; если появилось сообщение — см. «Журналы». |

**Журналы:** `%LOCALAPPDATA%\Programs\LogisticsContractor\logs\`
(`app.log`, `errors.log`, `audit.log`; с флагом `--debug` — ещё
`debug.log`). В журналах нет персональных данных — только имена полей,
количества и длины.

## Что и где лежит

Всё изменяемое — в папке программы `%LOCALAPPDATA%\Programs\LogisticsContractor`:

| Что | Где |
|---|---|
| Настройки | `config\settings.json` |
| База договоров | `contracts.db` |
| Готовые договоры | `output\<Водитель_И.О._маршрут_дата>\` |
| Журналы | `logs\` |
| Шаблоны, правовая база, иконки | `_internal\` (не менять) |

## Обновление

Запустите новый установщик поверх старой версии — он заменит программу,
а `config\`, `contracts.db` и `output\` сохранятся. Ключи в системном
хранилище тоже остаются: Windows хранит их отдельно от программы.

## Удаление

**Параметры → Приложения → Logistics Contractor → Удалить** (или ярлык
«Удалить Logistics Contractor» в меню «Пуск»).

Удаляются программа и журналы. Настройки, база и готовые договоры
**остаются** — их нужно удалить вручную, если они больше не нужны.
