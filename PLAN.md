# Дорожная карта проекта

## Цель

Автоматизировать полный цикл подготовки договоров перевозки: приём документов и текста из разных источников, извлечение реквизитов, заполнение формы, генерацию DOCX, проверку шаблонов и договоров по действующему законодательству РФ, хранение истории и результатов в SQLite.

## Ограничения

- GigaChat анализирует переданный текст, но не ищет изменения законодательства в интернете.
- Поиск новых публикаций выполняется отдельно через официальный портал `publication.pravo.gov.ru`.
- LLM предлагает анализ и правки, но не изменяет шаблоны и договоры автоматически.
- Проверяются все три шаблона: ООО, ИП с НДС и ИП без НДС.
- Стек проекта: Python 3.9+, PyQt5, SQLite, requests, docxtpl и python-docx.

## Архитектура

Импорт документов: текстовый PDF, DOCX и DOC читаются локально;
фото и сканированные страницы обрабатывает GigaChat Vision (локальный
Tesseract — резервный офлайн-режим). Ключ GigaChat хранится в системном
хранилище. Результат сопоставляется по полям и переносится только после
ручного подтверждения.
Проверка качества на личных снимках выполняется вручную без автоматических
платных запросов.

- Приём данных и распознавание: `ui/`, `core/gigachat_client.py`.
- Генерация документов: `core/contract_generator.py`, шаблоны DOCX.
- Источник и анализ законодательства: `core/legal_source.py`, `core/legal_filter.py`, `core/template_audit.py`, `core/legal_check_service.py`, `ui/legal_check_dialog.py`.
- Данные, версии шаблонов и проверки: `db/database.py` (SQLite).
- Настройки и журналы: `core/settings_service.py`, `logs/`.

## Риски

- Официальный REST API не подтверждён; каталог указывает CSV только за последние 90 дней.
- Актуальность набора и доступность портала из РФ требуют повторной проверки; страницы не ответили при проверке 27.09.2026.
- Полный текст акта может быть доступен только в PDF, что потребует надёжного извлечения текста.
- Доступность и стоимость GigaChat зависят от типа учётной записи и тарифов.
- LLM может ошибаться или галлюцинировать; юридическое заключение и любые изменения требуют проверки человеком.

## Что не делаем

- Не редактируем шаблоны и договоры автоматически без подтверждения пользователя.
- Не парсим Гарант и КонсультантПлюс.
- Не используем GigaChat API для интернет-поиска.
